`data.js` 한 파일만 고치면 돼요. (맨 위에 `내용은 여기서 바꾸면 돼요` 표시)

- 바탕화면: 비워두면 검은색. 사진을 쓰려면 `images/` 폴더에 넣고 `wallpaper: "images/wall.jpg"`
